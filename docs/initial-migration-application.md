## SQL integrity and UTF-8 BOM correction

The generated `.local/InitialCreate.sql` was reviewed offline. It contains only the two approved schemas, twelve application tables, platform migration history, reviewed constraints/indexes, and one history row for `20261012165516_InitialCreate`. It has no transaction wrappers so psql can enclose preflight, application, and postchecks in one transaction. No roles, grants, imports, or seed data are included. SHA256 of the originally reviewed SQL, including its leading UTF-8 BOM, is `52712DF08006723E4107411AD1BA37FCA2F33BB1D5E5B1DD88685119754C0F41`.

During Windows PowerShell application, the leading UTF-8 BOM (`EF BB BF`) caused a SQL parsing issue. Windows PowerShell UTF-8 text output can introduce a BOM; avoid rewriting SQL through `Get-Content`/`Set-Content` or `Out-File`. Removing only those three leading bytes produced the verified executable SHA256 `5E0850B11EFB5F97232DE4D630FA02116386B4BA1AE019D01521F665FF6FD53F`, without changing SQL text or line endings. All three committed SQL helpers use UTF-8 without BOM.

The workflow checks generated bytes against the original reviewed hash before removing a BOM. It accepts already BOM-free generation only if its hash matches the verified normalized hash and prepending a BOM reproduces the original reviewed hash. It validates UTF-8 and checks the final file hash before execution. Any other difference stops application.

Set-Location 'C:\Users\e21ni\Documents\SportStats'

$psqlExe = 'C:\Program Files\PostgreSQL\18\bin\psql.exe'

if ($LASTEXITCODE -ne 0) { throw 'Tool restore failed; stop.' }
& $dotnetExe restore SportStats.slnx
if ($LASTEXITCODE -ne 0) { throw 'Restore failed; stop.' }
& $dotnetExe build SportStats.slnx --no-restore
if ($LASTEXITCODE -ne 0) { throw 'Build failed; stop.' }

# Generates only SQL, without connecting; explicitly limits the initial migration.
& $dotnetExe tool run dotnet-ef -- migrations script 0 20261012165516_InitialCreate --project src/SportStats.Infrastructure --startup-project src/SportStats.Api --context SportStatsDbContext --output .local/InitialCreate.sql --no-build --no-transactions
if ($LASTEXITCODE -ne 0) { throw 'SQL generation failed; stop.' }
$sqlPath = Join-Path $PWD '.local/InitialCreate.sql'
$reviewedHash = '52712DF08006723E4107411AD1BA37FCA2F33BB1D5E5B1DD88685119754C0F41'
$normalizedHash = '5E0850B11EFB5F97232DE4D630FA02116386B4BA1AE019D01521F665FF6FD53F'
$sqlBytes = [System.IO.File]::ReadAllBytes($sqlPath)
$hasBom = $sqlBytes.Length -ge 3 -and $sqlBytes[0] -eq 0xEF -and $sqlBytes[1] -eq 0xBB -and $sqlBytes[2] -eq 0xBF
$generatedHash = (Get-FileHash -LiteralPath $sqlPath -Algorithm SHA256).Hash
if ($hasBom) {
    if ($generatedHash -ne $reviewedHash) { throw 'Generated SQL differs from the original reviewed bytes; stop.' }
    # Remove only the three BOM bytes; preserve every remaining byte.
    $normalizedBytes = New-Object byte[] ($sqlBytes.Length - 3)
    [System.Array]::Copy($sqlBytes, 3, $normalizedBytes, 0, $normalizedBytes.Length)
} else {
    if ($generatedHash -ne $normalizedHash) { throw 'Generated SQL differs from the verified BOM-free bytes; stop.' }
    $normalizedBytes = $sqlBytes
}
# Link normalized bytes back to the original review, even if generation had no BOM.
$originalBytes = New-Object byte[] ($normalizedBytes.Length + 3)
$originalBytes[0] = 0xEF; $originalBytes[1] = 0xBB; $originalBytes[2] = 0xBF
[System.Array]::Copy($normalizedBytes, 0, $originalBytes, 3, $normalizedBytes.Length)
$sha256 = [System.Security.Cryptography.SHA256]::Create()
try {
    $originalHash = [System.BitConverter]::ToString($sha256.ComputeHash($originalBytes)).Replace('-', '')
} finally { $sha256.Dispose() }
if ($originalHash -ne $reviewedHash) { throw 'Normalized SQL cannot reproduce the original reviewed hash; stop.' }
$strictUtf8 = New-Object System.Text.UTF8Encoding($false, $true)
$null = $strictUtf8.GetString($normalizedBytes) # Throws on invalid UTF-8.
[System.IO.File]::WriteAllBytes($sqlPath, $normalizedBytes)
if ((Get-FileHash -LiteralPath $sqlPath -Algorithm SHA256).Hash -ne $normalizedHash) {
    throw 'Normalized SQL integrity check failed; stop.'
}

# Connects as the migrator only. No password appears in arguments or output.
# All three files execute in one transaction; guards must pass before COMMIT.
& $psqlExe -X -W -1 -v ON_ERROR_STOP=1 -h 127.0.0.1 -p 5432 -d sportstats_dev -U sportstats_migrator -f docs/initial-migration-preflight.sql -f .local/InitialCreate.sql -f docs/initial-migration-verify.sql

if ($LASTEXITCODE -ne 0) { throw 'Post-application build failed.' }
& $dotnetExe test SportStats.slnx --no-build
if ($LASTEXITCODE -ne 0) { throw 'Post-application tests failed.' }

if ($LASTEXITCODE -ne 0) { throw 'Diff whitespace check failed.' }
